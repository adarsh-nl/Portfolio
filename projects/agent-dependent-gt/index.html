Agent-Dependent Ground Truth Biases Robustness Evaluation in Collaborative Perception

Collaborative perception is scored against an answer key assembled from the agents under test. Remove a collaborator and the key shrinks with it, so losing an agent looks cheaper than it is.

Adarsh Nanjaiya Latha Alessandro Chiumento Jan Laarhuis Ozlem Durmaz Incel

University of Twente, The Netherlands

01 · The problem

Average Precision assumes the answer key stays still

Collaborative perception lets a vehicle see past its own sensors by fusing what nearby agents broadcast. Its robustness is now studied by injecting faults (weather, sensor degradation, pose error, latency, agent dropout) and reading off the change in Average Precision. AP compares detections against a set of ground-truth objects, and it is normally safe to treat that set as a fixed property of the scene. Here it is not.

  1. What the toolchain does. OpenCOOD, and the two robustness benchmarks built on it, assemble ground truth as the union of the objects each participating agent annotates, after discarding agents beyond a 70 m communication radius.
  2. Where that breaks. Drop a collaborator and the union loses every object only that collaborator could see: exactly the objects beyond the ego's view that the collaboration was recovering.
  3. The consequence. Two effects partly cancel. Detections get worse, but the denominator shrinks with them, so recall is inflated and losing a collaborator appears less costly than it is.
  4. The question. How much of a reported degradation is the model losing information, and how much is the evaluation moving its own target?

The bias is not that the union is wrong. It is that an agent-set experiment silently changes the reference along with the agents.

Existing corruption benchmarks do not expose this, for a structural reason: the faults that trigger it are the ones that change the agent set. Corrupting a point cloud leaves every agent present and the union unchanged. Agent-count experiments, and the communication radius itself, are exposed.

02 · The mechanism

Build the reference yourself

Each agent \(i\) annotates the objects in its own sightlines, \(\mathcal{O}_i(s)\). The framework first keeps the agents within radius \(R\) of the ego, Eq. (1), then takes the union over whoever participates, Eq. (2). The standard protocol reports \(\mathrm{AP}(\mathcal{D}(\mathcal{A}'), \mathcal{G}(\mathcal{A}'))\): the same agent set determines both the predictions and the reference used to score them.

The sign is fixed

Because \(\mathcal{U}_j\) is by construction the set of objects no remaining agent annotates, dropping \(j\) removes precisely the objects the collaboration was recovering, Eq. (6). The effect therefore has a fixed sign and grows with \(|\mathcal{U}_j| / |\mathcal{G}(\mathcal{A}')|\), the fraction of the reference that only the removed agent contributed.

The limiting case is the ego itself. The ego cannot observe itself through its own sensors, so its box enters the reference only through another agent's annotation. In the Fig. 1 frame it sits at (0.51, 0.00) m in the ego frame. Remove the collaborator that annotated it and it leaves the reference together with the observation that could have supplied it. In the builder above, the ego's ring turns dashed when no participating agent sees it.

Which reference is correct is a choice, not a fact. The union answers a coherent question: how well do the surviving agents perceive what they collectively observe? An agent-dropout experiment usually asks a different one: what information is lost when that agent is gone? The departed collaborator's objects are still physically there. The paper reports both scorings side by side rather than declaring one universally correct.

03 · Reading the assembly code

One idiom, three codebases

The ground-truth assembly in OpenCOOD, DSRC and HEAL iterates over the agents present in the sample, collects object identifiers and deduplicates them by first occurrence, which is Eq. (2). All three use the same line:

# base_postprocessor.py, in all three codebases
[ids.index(x) for x in set(ids)]

A search of all three codebases found no mechanism that records the reference-set size or fixes the object set independently of the participating agents. RCP-Bench is built on HEAL and inherits the same construction. So the bias is present but uncorrected wherever an evaluation perturbs which agents participate.

05 · The protocol

Score the same detections twice

Official reference implementations of four collaborative detection models are wrapped in a fault-injection layer, without retraining or altering them. Every perturbed cell is scored twice from a single forward pass: once against the standard union reference, Eq. (3), and once against the reference held at the unperturbed scene, Eq. (4).

Standard, Eq. (3) \[ \mathrm{AP}\big(\mathcal{D}(\mathcal{A}'),\ \mathcal{G}(\mathcal{A}')\big) \]

Fixed, Eq. (4) \[ \mathrm{AP}\big(\mathcal{D}(\mathcal{A}'),\ \mathcal{G}_{\text{fix}}\big) \]

with \(\mathcal{G}_{\text{fix}} = \mathcal{G}(\mathcal{A}_R(s))\), the object set of the unperturbed scene. Only the reference argument differs.

Models at their released settings

Rather than retraining every method into one pipeline, as the existing benchmarks do, each model runs under its released configuration and checkpoint, on its authors' dataset, and is compared against its released benchmark number before anything is injected. That reproduction is what licenses the rest of the paper: degradation after injection is attributable to the fault, not to an unvalidated baseline. The trade-off is explicit: cross-model AP values are not strictly comparable, so degradation is reported within each model, never as a leaderboard.

06 · Magnitude

Drop every collaborator and 13.1% of the answer key disappears

The sample is stratified by the scene agent-count distribution of the split, and every frame's union count is checked against an independently built ground-truth cache; a disagreement fails the run rather than entering the results. In two-agent scenes, removing the collaborator is an ablation to single-agent perception rather than a graded change in collaboration.

Reporting the shrinkage alone would overstate the inflation. And there is a second mechanism, separate from recall inflation: restoring objects can raise precision. At four agents the corrected AP is higher than the as-is value, by 0.0007 at moderate and 0.0047 at severe severity, because detections the union scoring counted as false positives find their targets again: precision rises from 0.721 to 0.754 at the severe tier while recall dips slightly.

08 · The fault suite

Fourteen injectors, one that moves the target

The released suite covers the ways a collaborative system degrades, each at three severity levels: cooperative faults on the vehicle-to-everything link, LiDAR faults on the point cloud, camera faults on the image stream, and a cross-modal desynchroniser. All four evaluated models are LiDAR-only, so seven are exercised. Select one to see its tiers and whether it moves the reference.

The grid has 109 cells: 31 for each V2XSet model (one clean run, six injectors at three severities, and agent drop in four agent-count strata at three severities) plus 16 for CoSDH, whose released inference path raises an exception when a collaborator is removed. That is 221,764 frame-evaluations in total.

11 · Implications for evaluation practice

Three habits, each costing a quantity you already compute

  1. Record the reference-set size per cell. One integer. Without it a grid cannot be corrected after the fact, and a reader cannot tell whether a denominator moved between two compared cells.
  2. State which reference an agent-set intervention is scored against. Both choices are coherent, but the default is silent. Where the two scorings differ materially, as at every tier here, reporting both costs one column.
  3. Keep agent-set results per stratum and per model. Per-stratum clean references differ by up to 10.2 AP@0.7 within one model, so a pooled number describes no regime in the data; the noise floor is model-specific too.

12 · Limitations

What this does not yet show

  • The camera and cross-modal injectors are released but not exercised, because all four models are LiDAR-only. Occlusion that removes part of the scene while leaving the agent present is therefore outside the faults run.
  • The corrected scoring is measured on CoBEVT alone, on a 400-frame stratified sample. CoBEVT reproduces its benchmark and ships no injected noise, which isolates the denominator effect from any interaction with a noise-trained model; the released protocol applies unchanged to the other models.
  • At 19 test scenarios, the AP@0.7 correction has a consistent sign but its scene-bootstrap intervals include zero.
  • CoSDH cannot be graded against a released benchmark and is marked wherever it appears.
  • The code reading shows the same union in three codebases, so their agent-count evaluations are exposed. Those published agent-count results have not been re-scored under the fixed reference; that magnitude is not yet measured, and doing so is the natural next step.
