CoopFaultBench

Fault injection and dual-reference (fixed vs union) evaluation for cooperative (multi-agent) 3D perception.

Adarsh Nanjaiya Latha Alessandro Chiumento Jan Laarhuis Ozlem Durmaz Incel

University of Twente, The Netherlands

GitHub repository Release v0.1.0 Interactive walkthrough Paper page

The idea

Break the collaboration, then score it honestly

Cooperative perception lets vehicles fuse what their sensors see, and its robustness is studied by injecting faults and reading off the change in Average Precision. But the ground truth that AP is scored against is assembled as the union of what the participating agents see. When a fault removes an agent, that reference shrinks with it, so recall is inflated and losing a collaborator looks less damaging than it is.

CoopFaultBench does two things about that.

1 · Inject

Faults inside the real pipeline

Seven fault conditions, each at a mild, moderate and severe tier, run inside OpenCOOD's own, unmodified inference. Every draw is seeded per frame and agent, so a result does not depend on loading order.

Collaborators only pose error · latency · agent drop · missing LiDAR

All agents, incl. the ego point reduction · LiDAR fog · LiDAR snow

2 · Score twice

Union and fixed reference

The same detections are scored against the usual union reference and against a fixed reference, the union over the frame's full roster, and both are reported. The gap between them is how much of a measured degradation is the reference moving rather than the model losing information.

The repository also ships the paper's result payloads, with scripts that rebuild every table and figure on a CPU. No dataset content and no model weights are distributed.

In detail

See each fault at work

The interactive walkthrough puts every LiDAR-family injector in a live synthetic scene you can break yourself, tier by tier. The paper page explains why the reference moves and what fixing it changes. Installation, the quickstart and the full fault grid are in the README.
