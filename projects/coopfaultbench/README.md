# CoopFaultBench, code release page

Short concept page for the CoopFaultBench v0.1.0 release
(<https://github.com/adarsh-nl/CoopFaultBench>), the code accompanying the
WACV 2027 paper at `projects/agent-dependent-gt/`. Deliberately minimal: the
idea, the links, the licence in one line, and the citation. The detailed,
interactive treatment of the injectors is `projects/fault-injectors/`; the
fault grid, quickstart and reproducibility notes stay in the repository README.

Live at `/Portfolio/projects/coopfaultbench/`. Plain HTML. It reuses the paper
page's stylesheet (`../agent-dependent-gt/adgt.css`); `cfb.css` adds only what
this page needs, and `cfb.js` is the BibTeX copy button.

Every statement is taken from the repository at tag `v0.1.0` (README,
`docs/injectors.md`, `NOTICE`, `CITATION.cff`). No result numbers appear here.
Add pages/DOI to the BibTeX once `CITATION.cff` has them.

`media/agent-drop.jpg` is a crop (titles and legends removed, JPEG) of
`results/fault_injector_visualisation/agent_drop/v2xset_contact.png` from the
earlier public repo <https://github.com/adarsh-nl/Fault-Injectors>; the tier
labels under it are HTML so they stay sharp and readable.
